# 「禾医」华为云部署指南

> 目标：从本地演示环境平滑迁移到华为云，形成可公开访问的在线演示地址。
> 全程约30~60分钟。按顺序执行；涉及控制台操作的步骤以华为云最新界面为准。

## 0. 本地先行（已验证）

```bash
cd he-yi
pip install -r requirements.txt
python model/train_light.py          # 生成Demo基线模型(可选, 仓库已带)
python -m uvicorn backend.main:app --port 8000
# 浏览器打开 http://127.0.0.1:8000
```

## 1. 开通华为云资源

| 资源 | 用途 | 规格（够用即可） |
|---|---|---|
| ECS 弹性云服务器 | 跑 FastAPI 应用 | 2vCPU/4GB, Ubuntu 22.04 |
| OBS 对象存储 | 存原图/数据集/模型工件 | 默认桶 `heyi-artifacts` |
| ModelArts | 训练ResNet + 在线服务 | 按需计费, 训练选单卡GPU(或昇腾) |
| ModelArts Studio(MaaS) | 大模型API(智能体语言层) | 开通即送免费额度 |
| RDS for MySQL（可选） | 替换SQLite存诊断档案 | 最小规格 |

## 2. ModelArts 训练主模型（正式指标来源）

1. OBS 上传数据集：
   - 本地执行 `python data/download_dataset.py --dest data/plantvillage`（约800MB）
   - 上传 `data/plantvillage` 目录至 `obs://heyi-artifacts/plantvillage/`
2. ModelArts 控制台 → 训练管理 → 创建训练作业：
   - 代码目录：上传 `he-yi/model/`；
   - 启动文件：`train_mindspore.py`（推荐，体现昇思栈；或 `train_pytorch.py`）
   - 数据存储位置：`obs://heyi-artifacts/plantvillage/`
   - 资源：GPU/P4 或 昇腾910 规格；`--epochs 8 --batch 64`
   - 训练输出：`obs://heyi-artifacts/checkpoints_ms/`
3. 训练完成：下载 `best.ckpt` + `meta.json`，放到本地/服务器 `model/checkpoints_ms/`，
   服务重启后推理引擎自动切换为 `mindspore`（`/api/health` 可验证）。

## 3. MaaS 大模型接入（智能体润色层）

1. ModelArts Studio 控制台 → 模型服务 → 选择模型（如 DeepSeek-V3 / Qwen）→ 创建 API Key；
2. 在服务器环境变量配置（OpenAI兼容，无需改代码）：
   ```bash
   export HEYI_LLM_BASE_URL=https://api.modelarts-maas.com/v1
   export HEYI_LLM_API_KEY=<你的Key>
   export HEYI_LLM_MODEL=DeepSeek-V3
   ```
3. 重启服务后 `/api/health` 中 `llm:true`，前端"知识库模式"标签自动变为"大模型已连接"。

## 4. 应用上云（ECS）

```bash
# ECS(Ubuntu)上
sudo apt update && sudo apt install -y python3-pip
git clone <你的仓库> he-yi && cd he-yi
pip3 install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
- 安全组放行 8000（或用 Nginx 反代 80/443）；
- 建议配 systemd 常驻：
  ```ini
  # /etc/systemd/system/heyi.service
  [Service]
  WorkingDirectory=/root/he-yi
  Environment=HEYI_LLM_BASE_URL=...
  Environment=HEYI_LLM_API_KEY=...
  ExecStart=/usr/local/bin/uvicorn backend.main:app --host 0.0.0.0 --port 8000
  Restart=always
  ```
- 访问 `http://<ECS公网IP>:8000` 即为在线演示地址（答辩前建议绑定域名+HTTPS）。

## 5. 可选增强

- **图片入OBS**：`/api/diagnose` 中把原图 PUT 到 `obs://heyi-artifacts/uploads/`（引入 `esdk-obs-python`）；
- **档案库升级RDS**：`backend/main.py` 的 sqlite3 连接串替换为 pymysql（表结构不变）；
- **IoTDA 联动**：田间相机 -> IoTDA 设备接入 -> 规则引擎转发 -> 调用 `/api/diagnose`，实现定时巡检自动诊断；
- **鸿蒙端**：前端接口即 REST，用 ArkTS `@ohos.net.http` 封装即可。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| `/api/health` 显示 heuristic | 未放置任何模型权重：跑 `train_light.py` 或放入训练产物 |
| MaaS 调用 401 | 检查 API Key 与所属账号区域是否一致 |
| 上传图片报400 | 仅支持JPG/PNG；前端已做预览校验 |
| 训练OBS路径权限 | ModelArts 需授予桶读写权限（委托） |
