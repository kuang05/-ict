# 演示视频录制脚本（3~4分钟，1080p，配套字幕）

> 工具：OBS Studio录屏 + 剪映加字幕；语速平缓，每个环节留操作停顿。

## 镜头1：开场（15s）
画面：PPT/P1封面或平台首页
口播：
"这是「禾医」——农作物病虫害智能诊断与防控决策平台，参加第十一届华为ICT大赛创新赛，
基于华为云 AgentArts 智能体开发平台构建；识别底座在昇腾 910B 上用 PyTorch + torch_npu 训练，
经 ATC 转为 Ascend310B4 端侧 OM；语言层由 MaaS 大模型驱动。"

## 镜头2：痛点引入（20s）
画面：晚疫病毁田照片/新闻截图 → 切到"通用大模型幻觉回答"截图
口播：
"晚疫病这类暴发性病害三到七天就能毁掉整棚番茄；而直接问通用大模型'打什么药'，
它可能编造不存在的农药——农业生产中，幻觉就是事故。"

## 镜头3：诊断主链路（45s）
画面：平台首页 → 拖入晚疫病叶片照片 → 点击"开始智能诊断" → 停留在结果页滚动展示
口播：
"上传一张感病叶片。一秒内返回识别结果：番茄晚疫病，置信度 95%（本机实测值）。
下方是禾医智能体生成的四段式报告：典型症状、发病条件、立即处置、农事预防。
请注意这条红色升级卡——晚疫病是暴发性病害，系统自动提示隔离病株并联系当地植保站。
每一个用药名称都来自内置植保知识库，可溯源、零幻觉。"

## 镜头4：对照与问答（45s）
画面：上传健康叶片 → 显示"苹果健康叶片"无升级卡；
     再在右侧问答框输入"玉米叶子上锈色的粉是什么病？" → 展示回答与引用来源
口播：
"换一张健康叶片，识别为健康状态，没有误报升级。
左侧的农事问答智能体支持自然语言提问，回答基于知识库检索（RAG）生成，
并标注了引用的病害条目——这是'检索增强'而非'凭记忆作答'。"

## 镜头5：技术架构（30s）
画面：架构图（P3）
口播：
"系统采用三级推理引擎：生产路径是在昇腾 910B 上用 PyTorch + torch_npu 训练的 ResNet 迁移模型，
经 ATC 转换后可在 Ascend 310B4 上离线部署；轻网环境自动降级轻量模型；链路永不中断。
智能体把'事实'与'语言'分层：四个工具负责知识库查询与处方生成，
MaaS大模型只负责把事实讲成农户听得懂的话。"

## 镜头6：价值与愿景（25s）
画面：诊断记录列表滚动 → 数据资产图表占位 → P10/P11
口播：
"每一次诊断都会沉淀为区域病害数据资产，服务于植保部门测报预警。
下一步我们将把端侧迁移到鸿蒙App，接入田间物联网相机实现自动巡检，
用昇腾边缘盒支持离线诊断——让每一个小农户都有一位口袋里的植保专家。
禾医，为农作物保驾护航。谢谢观看。"

---
## 录制清单核对
- [ ] 1080p/30fps，码率≥8Mbps
- [ ] 中文字幕全程
- [ ] 结果页停留≥3s，升级卡给特写
- [ ] 预先清理浏览器书签/通知
- [ ] 知识库模式标签是否显示"大模型已连接"（若已配MaaS，提一句"大模型已接入华为云MaaS"）
