# 禾医 · 真正的解决办法：田间域自适应自监督预训练

> 2026-10-08。本文回答：**为什么继续调参不会有质变？真正的出路在哪？**

---

## 一、问题的本质不是"模型不够大"，而是"没见过田间"

| 域 | 数据 | 特点 |
|---|---|---|
| 源域 PlantVillage | 54k 张 | 实验室、**单一均匀背景**、光照稳定 |
| 目标域 PlantDoc | 2,598 张（我们用到 6,723 crop） | 真实田间：**杂乱背景、多变光照、遮挡、多叶片、土壤/杂草干扰** |

v1 基线（实验室模型直接上田间）只有 **28.3%** —— 这就是域偏移的代价。

**已经排除的路线**（实测证伪，不是猜测）：

| 尝试 | 结果 | 结论 |
|---|---|---|
| 分辨率 224→288 | 66.81% < 67.92% | 无益 |
| 更长训练（30ep） | 61.28% | 有害 |
| MixUp + EMA | 61.28%（v15）/ 64.38%（v13） | **有害** |
| 30 类扩展 + pd_repeat=1 | 64.38% | 有害 |
| 4 模型同构集成 | 66.59% | 不如单模型 |

**外部证据**（IEEE ICETCI 2026，14 个模型变体的系统研究）：
> "a **data ceiling** that caps inductive alignment **regardless of scale** …
> Closing the remaining gap likely requires **target-domain pretraining** or alignment objectives
> that exploit structure beyond marginal or class-conditional feature distributions,
> **not larger models alone**."

**换句话说**：在目标域数据量不变的前提下，换更大的骨干、调更好的超参，都撞天花板。
**必须让模型先"见过田间"。**

---

## 二、我们手上恰好有 11 万张田间图（此前完全没用）

排查数据资产时发现：

| 资产 | 规模 | 状态 |
|---|---|---|
| `~/data/hf_field`（HF `Saon110/bd-crop-vegetable-plant-disease-dataset`） | **111,165 张真实田间图**（~17GB） | **此前只提取了 11 个类的 ~2 万张**，其余 ~9 万张闲置 |
| `~/data/kaggle/corn` | 4,187 张（4 类） | 已并入 pv_extra，但 `Blight` 1,146 张未用 |
| `~/data/kaggle/field_seg` | 960 张 | 未用 |

**关键**：hf_field 的类别是 Banana / Cauliflower 等，**不属于我们的 27 类**，
所以**不能作为有标签数据**——但**自监督学习根本不需要标签**。

它们的价值在于**域**而非**类**：这 11 万张图提供了大量"真实田间成像条件"的样本
（杂乱背景、自然光、多叶片、病害斑点纹理），正是模型缺失的那一课。

## 三、方案：DAP-SimCLR（领域自适应预训练）

```
ImageNet 预训练权重
      │
      ▼
┌─────────────────────────────────────────┐
│ 阶段 1：田间域自适应自监督预训练 (DAP)      │
│   数据：111,165 张田间图（无标签）           │
│   方法：SimCLR 对比学习                     │
│     · 双视图强增强(RRC/翻转/颜色抖动/灰度/模糊)│
│     · 2 层 MLP 投影头 + NT-Xent(τ=0.5)      │
│     · 160px, batch 256, 20 epoch, FP16      │
│   产出：见过田间的 backbone（ssl_r50.pth）   │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│ 阶段 2：有监督微调（层次化双头）             │
│   数据：PlantVillage + pv_extra + PlantDoc  │
│   方法：train_hier.py --init ssl_r50.pth    │
│   产出：best_ssl_ft_r50.pth → 评测           │
└─────────────────────────────────────────┘
```

### 为什么这样设计

1. **直击论文指出的出路**：target-domain pretraining —— 而且是**真正的目标域成像条件**，
   不是通用自然图像。
2. **零标签成本**：11 万张图完全不需要人工标注，这是唯一能"凭空增加田间经验"的途径。
3. **风险可控**：从 ImageNet 权重出发做 **继续预训练**（而非从零 SSL），
   即使 SSL 收益有限，也不会破坏骨干的通用表征。
4. **与已有创新正交**：DAP 提升的是 backbone 的域鲁棒性，
   层次化双头提升的是标签结构利用，MixStyle 提升的是特征层风格对齐——三者可叠加。

### 工程实现

| 脚本 | 作用 |
|---|---|
| `model/extract_ssl_corpus.py` | parquet → **192px JPEG**（111k 张仅占 **1.1G**，避免 17GB 占满磁盘） |
| `model/ssl_pretrain.py` | SimCLR 预训练，产出 `backbone.*` 键的 ckpt，可被 `--init` 直接加载 |
| `scripts/run_ssl_chain.sh` | 等 world 链完成后自动接：SSL 预训练 → 微调 → 评测 |

## 五、如果 DAP 有效，下一步

1. **换更大骨干做 SSL**（ResNet101 / ConvNeXt-T），把 DAP 收益与骨干收益叠加
2. **半监督自训练**：用 DAP 模型对未标注田间图打伪标签，高置信样本回流训练
3. **并入 kaggle/corn 的 `Blight` 1,146 张**（核实语义后）补强高危弱类
   `Corn___Northern_Leaf_Blight`（test 仅 12 张，是高危漏诊的重灾区）

## 六、一句话总结

**过去所有优化都停留在"用同一批数据、同一个域"里调模型，撞的是数据天花板；
真正的解法是给模型补上它从没见过的"田间"这一课——而我们有 11 万张现成的田间图，
只是从来没被用上。**
