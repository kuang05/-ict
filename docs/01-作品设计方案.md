## 一、选题背景与真实需求

### 1.1 行业痛点（真实问题）
- **发现难**：我国主要农作物病虫害年发生面积60~70亿亩次，基层植保员与农户比例严重失衡；传统诊断依赖"老把式"经验，误判率高。
- **识病害人**：晚疫病、黄龙病等暴发性病害从发病到毁田仅3~7天，错过最佳防治窗口即绝收——番茄晚疫病未防控损失可达100%。
- **防治盲目**：农户"凭感觉打药"，过量用药普遍；缺乏"对症、适时、适量"的处方化指导，既增加成本又造成农残与面源污染。
- **知识断层**：植保知识散落在教材与网页，农户查询门槛高，通用大模型直接回答存在幻觉风险（编造农药名称/剂量，农业生产中不可接受）。

### 1.2 政策与产业契合
- 契合《"十四五"全国种植业发展规划》"虫口夺粮"保丰收行动与乡村振兴数字乡村建设。
- 智慧农业是历届大赛评委认可的高价值方向（往届创新赛全球特等奖作品"Atlas Guardian智慧农业巡检机器人"即同赛道）。

## 二、作品概述

「禾医」是一个"**端上拍照 → 云上诊断 → 智能体开方 → 全程留痕**"的农作物病虫害智能诊断平台：

1. 农户上传叶片照片，AI识别模型给出38类（14种作物×26病害+12健康）病害候选；
2. 农事智能体基于**内置植保知识库**生成"诊断报告 + 用药处方 + 农事预防 + 复诊监测"四段式方案，高危病害（晚疫病、病毒病、黄龙病）自动**升级预警**；
3. 支持自然语言农事问答（RAG检索知识库作答，杜绝幻觉）；
4. 全部诊断记录入库，形成病害发生时空数据资产，为区域测报提供数据底座。

## 五、核心创新点

1. **【首要】「实验室→田间」跨域泛化：真实田间准确率 28.3% → 69.82%（+41.5 个百分点，2.47×）**

   > **口径说明（诚实优先）**：对外主口径采用 **69.82%** ——
   > **原图级 5 折交叉集成**：每折用 80% 数据训练、**用留出集（val）选模型**，
   > 5 折并集覆盖 **100% 训练数据**，全部在无泄漏的 pd_v3 上训练，**不依赖任何测试集信息**。
   > 单折 = **66.67% ± 1.05%**（n=5，极差 2.70pp）→ **方差极小，证明该水平不是某一次划分的运气**。
   > 对照口径：8 模型先验集成 **69.59%**（含代价敏感成员，**高危判成健康率更低：5.50%**）；
   > 含测试集信息的 9 模型集成 **70.05%**（仅作技术上限，不作主口径）。
   > 详见 `docs/20-优化结果汇总与世界水平对标.md` 第二节。

   农作物病害识别的真正难题不在"实验室里分得多准"，而在**模型能否走出实验室**。
   本作品实测：PlantVillage 实验室数据上 99.31% 的模型，直接用于 PlantDoc
   **真实田间照片时只有 28.3%** —— 这就是域偏移（domain shift），
   也是绝大多数植物病害 AI 项目"演示很准、下地就废"的根因。

   本作品针对性提出一套**跨域泛化方案**（详见 `docs/06-跨域优化与实验记录.md`）：

   | 手段 | 作用 |
   |---|---|
   | **MixStyle 特征层域泛化**（Zhou et al., CVPR 2021） | 训练时随机混合样本通道均值/方差，迫使模型不依赖背景、光照等域相关低层统计 |
   | **输出空间收缩为 27 类** | 消除"把番茄叶判成马铃薯叶"这类与病害识别无关的系统性失分 |
   | **原图级划分 + 目标域监督** | 同株多叶片不跨训练/验证集（防泄漏），并用田间验证集选模型而非实验室验证集 |
   | **类别平衡采样 + 强增强** | 缓解田间数据长尾（Blueberry 827 张 vs Apple Scab 157 张） |

   **实测结果**（PlantDoc **原图级留出 test**，多尺度 TTA × 水平翻转；
   已剔除 8 张与训练集同内容的泄漏样本，**444 个标注叶片**）：

   | 阶段 | 田间 top1 |
   |---|---|
   | 基线（实验室模型直接上田间） | 28.3% |
   | + 强增强域泛化 | 32.5% |
   | + 田间数据微调（v1） | 56.6% |
   | + MixStyle 域泛化 + 27类输出空间（v3） | 66.81% |
   | + 现代骨干（ConvNeXt-22k）/ 层次化双头 / 田间自监督预训练 | 65~67%（单模型，差异在噪声内） |
   | **+ 5 折交叉集成（本作品对外主口径，覆盖 100% 训练数据）** | **69.82%** ✅ |
   | ↳ 单折均值 ± 标准差（n=5） | 66.67% ± 1.05% |
   | 对照：8 模型先验集成（含代价敏感成员，高危漏诊更低） | 69.59% |

   误差归因显示：作物识别率由 74.1% 提升至 **88.3%**，病害判别（作物判对时）达 **79.1%**，
   即增益主要来自消除**跨作物混淆**与**集成降方差**。

   **方法学说明（诚实披露）**：444 样本的 95% 置信区间约 **±4.4pp**，
   单模型之间 2~3pp 的差异**统计上不可区分** —— 这既解释了为什么单个"改进"
   看起来都无效，也说明**集成是本任务上唯一稳定的增益来源**（详见 `docs/20`）。

   **与同类工作对比**：同任务（PlantVillage→PlantDoc）的 *Sensors* 2026（26(12):3632）
   采用 EfficientNet-B0 + ProtoNet + 目标域 BN 校准，在**少样本**设定下
   5-shot 为 54.24%；本作品利用 PlantDoc 有标签训练集做**全监督域适应**，
   在更严格的 27 类全量分类下达 **69.82%**（5 折交叉集成；8 模型集成对照 69.59%）。

2. **防幻觉的"事实-语言"分层智能体**（对齐本届"智能体开发"考察点）
   通用大模型在农业用药上幻觉即事故。本作品把Agent拆为**工具层**（知识库精确查询/检索/处方生成/高危升级四个Tool）与**语言层**（MaaS大模型仅做事实的通俗化改写），报告中每个用药名称、剂量、间隔天数均可溯源到知识库条目——可信AI落地设计。
3. **高危病害自动升级机制**
   知识库为每种病害标注severity，晚疫病等暴发性病害、病毒病等无特效药病害触发**红色升级卡**（联系植保站/隔离病株），把"诊断"延伸为"防控决策"。
4. **背景掩膜色度学特征 + 三级推理引擎的工程降本设计**
   摄影棚白底被掩膜剔除后统计叶面病斑色度特征；三级引擎（ResNet→轻量质心模型→裸规则）保证弱网/低成本终端永远有输出，轻量模型以纯numpy实现（无框架依赖，可跑在任意边缘设备）。
5. **诊断数据资产化**
   每次诊断写入档案库，积累的"区域-作物-病害-时间"四元组可直接服务植保部门测报预警，作品具备从工具到平台的外延。

## 六、数据与模型

- **数据集**：PlantVillage公开数据集（Mendeley官方打包版，55,448张、14种作物、26种病害+背景类、39分类标签），源：`spMohanty/PlantVillage-Dataset`（GitHub）/ `OmniData/PlantVillage`（ModelScope国内镜像）；本仓库附`download_dataset.py`全量下载脚本与108张演示子集。
- **主模型（已训练完成，真实指标）**：ImageNet预训练ResNet18迁移学习（冻结浅层、微调layer4+分类头，标签平滑0.1，AdamW+余弦退火）
  - **验证准确率：99.31%**（随机分层5%验证集=2,772张、覆盖全部39类，seed=42可复现）
  - 训练曲线：ep1 98.92% → ep6 99.31%（best saved）→ ep8 99.24%
  - 训练环境：AMD Radeon PRO W7900（ROCm 7.2.4 + PyTorch 2.10），batch 128，每轮27~31秒，8轮约4.5分钟
  - 训练产物：`model/checkpoints/best.pth` + `meta.json`（已随仓库提交，含类别表与指标）
- **田间域适应模型（本作品主力，最终交付为 9 模型异构集成 + 5 尺度 TTA）**
  - **PlantDoc 真实田间 top1：69.82%**（5 折交叉集成，无泄漏干净测试集 444 叶片；top3 86.9%，
    作物识别率 **89.41%**，作物判对时病害判别 **79.3%**）
  - 对照：实验室模型直接上田间仅 28.3%，**相对提升 +41.8 个百分点（2.48 倍）**
  - 集成成员（刻意覆盖不同骨干/年代/训练范式，追求多样性）：
    `R50 + R50@288 + R101 + R101@288 + R101双头 + ConvNeXt-T/22k + ConvNeXt-S/22k ×2种子 + R50+SSL-DAP`
  - 单模型最优：v11（R101@224, 27类, MixStyle）**67.92%**
  - 训练协议：PlantVillage 27 类子集（每类 600）+ PlantDoc train 裁叶 ×3 + 外部田间图（pv_extra 23,934 张），
    按**原图级**划分 train 6720 / val 1714 / test 452（同株多叶片不跨集，**三方 MD5 交集为 0**）
  - 模型选择依据 **PlantDoc val**（目标域），而非实验室验证集
  - 完整实验记录与结果文件：`docs/18`（审计）、`docs/19`（田间自监督）、`docs/20`（结果汇总与对标）、
    `results/BEST_ensemble9_CLEAN.json`
  - **已证伪路线**（避免夸大）：更大分辨率 / 更长训练 / MixUp+EMA / 30类扩展 / 权重汤 / 同族模型堆数量
    均无增益或有害，详见 `docs/20` 第五节
- **Demo基线模型**（随仓库可复现）：背景掩膜色度学特征（4病斑占比+10-bin色相直方图+暗斑聚集度）+ 最近邻(k=3)分类，108张6类子集上测试准确率75%——仅用于演示链路降级兜底，提交材料中如实标注。
- **端到端回归**：训练模型接入平台后，6类演示集108张全链路诊断 **108/108=100%**（含命名归一修复）。
- **知识库**：39类病害结构化知识（症状/病原/发病条件/预防/治疗/不干预风险六字段），6类演示类别含完整处方级内容；已修复Mendeley/GitHub两套数据集命名的别名归一（玉米/樱桃等类）。

## 十、竞品分析与差异化定位

| 产品 | 定位 | 能力 | 与禾医的差异 |
|---|---|---|---|

**禾医的四个差异化点（竞品均未同时具备）**：
1. **可溯源防幻觉处方**：每个药名剂量可溯源知识库条目（竞品为黑盒输出，幻觉风险不可控）；
2. **高危病害自动升级**：晚疫病/病毒病/黄龙病触发红色预警并指引联系植保站（竞品止步于"识别结果"）；
3. **三级降级推理引擎**：弱网/低成本终端永远有输出（竞品依赖在线服务）；
4. **诊断数据资产化**：区域-作物-病害-时间四元组沉淀，服务植保测报（竞品数据不回流公共测报体系）。

## 十一、局限性与改进路线（含田间域差实测）

### 11.1 域差实测（诚实数字）

在同分布验证集99.31%之外，我们用 **PlantDoc真实田间数据集**（236张网络采集的真实田间照片、27类、452个人工标注叶片目标）对训练模型做了零样本域差评测（`model/eval_plantdoc.py`，结果文件`docs/plantdoc_eval_result*.json`）：

| 阶段 | 方案 | 田间真实图像(PlantDoc) top1 |
|---|---|---|
| ① | 基线（实验室模型直接上田间） | **28.3%** |
| ② | + 强增强域泛化 | 32.5% |
| ③ | + 田间数据监督微调（v1） | 56.6% |
| ④ | + MixStyle 域泛化 + 27类输出空间（v3） | 66.81% |
| ⑤ | **+ 5 折交叉集成（对外主口径，覆盖 100% 训练数据）** | **69.82%** |

**结论**：实验室→田间的域差真实且巨大（基线 -71pp），单纯增强几乎无效（+4.2pp）；
真正有效的是**特征层域泛化 + 输出空间对齐 + 目标域监督 + 集成降方差**的组合（①→⑤ 共 **+41.8pp**）。
误差归因表明作物识别率由 74.1% 升至 **89.4%**，即主要消除了跨作物混淆。

### 11.2 仍然诚实的局限（不回避）

1. **同作物内细粒度病害区分仍是瓶颈**：作物认对的前提下，病害判对率 **79.3%**——
   例如番茄早病/晚病/叶霉病之间仍会混淆，这是下一步主攻方向。
2. **昇腾 NPU 训练已完成**：全部模型（v3 → v16、层次化 v4-hier、ConvNeXt 系列、SSL-DAP、多任务）
   均在**华为云 ModelArts 昇腾 910B** 上完成训练，并已通过 ATC 转换产出
   **Ascend310B4 OM** 端侧模型（`heyi_v11_Ascend310B4.om` 86MB / `w2_convnexts_...om` 120MB）。
   证据链：昇腾训练日志 + OM 产物 + ATC 转换日志。
3. **数据仍为公开数据集**：PlantVillage + PlantDoc + 公开田间图集，
   缺少本地一手田间样本，已列入采集计划。
4. **69.82% 意味着仍有约 30% 会判错**：本作品定位为**筛查与决策支持**，
   而非替代植保员确诊；且通过**置信度守门**（τ=0.4 时 21.8% 样本转人工），
   **高危病害判成健康的比例可压到 0**。
5. **测量噪声必须披露**：444 样本的 95% 置信区间约 ±4.4pp，
   单模型间 2~3pp 差异统计上不可区分（详见 `docs/20`）。

### 11.3 对承诺指标的使用规范（对外统一口径）

- **主推表述**：「PlantVillage 验证集 **99.31%**；PlantDoc 真实田间 **69.82%**
  （基线 28.3%，**+41.3 个百分点，2.46 倍**）」
  （基线 28.3%，**+41.8 个百分点，2.48 倍**）」
- 不使用"达到 SOTA"（PlantVillage 上论文级 SOTA 为 99.8%+ 的 ViT 类模型）；
- **不回避** 69.82% 的含义：仍有约三成会判错，产品定位为筛查辅助；
- **主动披露测试集信息的使用边界**：集成成员与 TTA 尺度均按**先验规则**选定（口径 A）；
  任何依赖测试集结果的选择（口径 B 的 70.05%）**单独标注、不作主口径**；
- **不回避** 评测样本量（444）带来的 ±4.4pp 不确定性；
- 不使用未经本作品实测的第三方数字。
