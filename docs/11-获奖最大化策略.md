# 禾医 · 获奖最大化策略（目标：特等奖 / 一等奖）

> 前提：**不怕难，只要最可能拿最高奖。**
> 本文的判断依据是"往届特等奖作品的实际形态"，不是"哪个赛道容易"。

## 一、往届特等奖长什么样（形态规律）

| 届次 | 特等奖作品 | 形态 | 关键要素 |
|---|---|---|---|
| 8 | 同济"航济" | 蛇形机器人 + 航空发动机损伤检测 | **软硬一体** + 现场采集真数据 |

**提炼出 4 条特等奖共性**：

1. **软硬一体**（5 个里 4 个有实体硬件载体）—— 纯软件想拿特等奖极难
2. **真数据**（现场采集，不是公开数据集）
3. **强社会价值**（普惠 / 绿色发展 / TECH4ALL，这些荣誉奖也常与特等奖重叠）
4. **量化表达**（每个亮点都有数字）

> 对照：禾医现在是**纯软件**（Web + 后端 + Agent），有技术深度但**形态不对**。

## 三、赛道选择（获奖最大化视角，不是难度视角）

| 赛道 | 能否让"跨域泛化"成为**技术主线** | 竞争 | 判断 |
|---|---|---|---|
| **赛题一** 华为云产品 | **能** ✅ "AI 创新应用"的核心就是 AI 能力，模型攻坚可以当主角 | 激烈 | **主攻** |
| 赛题二 AgentArts | 弱 ⚠️ 重心被拉到"智能体编排"，跨域泛化沦为附属 | 中高 | 备选 |
| 赛题三 Nexent | 不匹配 ❌ | 低 | 放弃 |

**为什么选赛题一（而不是更容易的赛题二）**：

1. **我们的王牌是技术深度，不是平台熟练度。** 赛题一考"AI 创新应用"，
   正好让"把田间准确率从 28% 拉到 66.8%"成为主线；赛题二考"Agent 编排"，
   我们的技术优势发挥不出来。
2. **竞争激烈≠拿不到奖。** 大多数队伍是"调个 API + 搭个界面"的应用堆砌，
   **有真技术攻坚的队伍反而稀缺**。评委见过太多套路，见到真实验对比会记住。
3. **要求明确**（CodeArts + RDS + Redis + 部署 + 开源），做扎实就符合资格；
   赛题二的"可视化 Demo / 社媒帖"更依赖主观判断。

## 七、一句话总结

**禾医的护城河是"把田间准确率从 28% 拉到 66.8%"这个真技术攻坚，
不是"用平台搭了个智能体"。所以赛道要选能让技术当主角的那条（赛题一），
同时补上特等奖必备的三件套：硬件载体、真数据、云服务链。**
