**提炼出 4 条特等奖共性**：

1. **软硬一体**（5 个里 4 个有实体硬件载体）—— 纯软件想拿特等奖极难
2. **真数据**（现场采集，不是公开数据集）
3. **强社会价值**（普惠 / 绿色发展 / TECH4ALL，这些荣誉奖也常与特等奖重叠）
4. **量化表达**（每个亮点都有数字）

> 对照：禾医现在是**纯软件**（Web + 后端 + Agent），有技术深度但**形态不对**。

## 三、赛道选择（获奖最大化视角，不是难度视角）

| 赛题 | 能否让"跨域泛化"成为**技术主线** | 竞争 | 判断 |
|---|---|---|---|
| **赛题二** AgentArts | **能** ✅ 跨域识别模型注册为平台 MCP 工具、作为智能体识别底座，"把田间准确率从 28% 拉到 66.8%"就是技术主线 | 中高 | **主攻** |
| 赛题一 华为云产品 | 能，但需补齐 CodeArts/RDS/Redis 工程链，与现有资产错位 | 激烈 | 不选 |
| 赛题三 Nexent | 要求多模态数据资产 + 知识图谱本体，与禾医资产不匹配 | 低 | 不选 |

**为什么选赛题二**：

1. **资产直接咬合，且技术深度照样当主角。** 禾医的智能体/知识库/MCP/Skills
   与 AgentArts 平台要求一一对应；识别模型注册为 MCP 工具后，跨域泛化攻坚
   仍是作品的硬核创新点，不会被编排工作稀释。
2. **平台护栏强，差异化反而更稀缺。** 大多数队伍是"平台拖拽编排 + 调 API"，
   **有真模型底座 + 防幻觉设计 + 完整评测的智能体反而稀缺**。
   评委见过太多套路，见到真实验对比会记住。
3. **要求明确可自查**（AgentArts 构建-编排-部署 + 可视化 Demo + 社媒分享帖），
   交付清单明确，做扎实就符合资格。
