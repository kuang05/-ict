## 二、一句话简介

> **禾医**是一个"**拍照 → 诊断 → 开方 → 留痕**"的农作物病虫害智能诊断平台：
> 农户用手机拍一张病叶照片，即可在秒级获得**可溯源的防治处方**与**高危病害升级提醒**，
> 并把每次诊断沉淀为区域病害数据资产。
> 其核心技术贡献是：**把模型在真实田间的准确率从 28.3% 提升到 66.81%**
> （相对提升 2.4 倍），并**首次针对高危病害单独优化漏诊率**。

## 三、真实需求与痛点（来自真实场景）

| 痛点 | 现状 | 后果 |
|---|---|---|
| **发现难** | 我国主要农作物病虫害年发生面积 60~70 亿亩次，基层植保员与农户比例严重失衡 | 依赖"老把式"经验，误判率高 |
| **识别难** | 晚疫病、黄龙病等暴发性病害**3~7 天可毁田** | 错过防治窗口即绝收 |
| **用药盲目** | 农户"凭感觉打药"，过量用药普遍 | 成本增加 + 农残 + 面源污染 |
| **知识断层** | 植保知识散落教材网页；通用大模型直接回答会**编造药名剂量** | 农业场景下幻觉即事故 |

**为什么现有 AI 方案不管用**：实验室数据集（PlantVillage）上准确率普遍 99%+，
但**搬到真实田间就崩到 20~40%**——这是行业公开承认的"实验室→田间"域偏移难题，
也是本项目要解决的核心问题。

## 四、解决方案概述

```
【端】手机拍照（PWA，可添加到主屏幕）
   │  HTTPS
【云】华为云 AgentArts（智果）智能体开发平台
   ├─ 平台层：单智能体/工作流/多智能体三种模式构建与编排（分诊/识别/处方/审计/升级五Agent）
   ├─ 智能体层：事实约束型农事 Agent（防幻觉）；识别模型注册为 MCP 工具，知识库接入平台 RAG
   ├─ 推理层：三级自适应引擎（深度模型 → 轻量模型 → 规则兜底）
   └─ 数据层：诊断档案 / 病害时空数据资产
   │
【决策输出】诊断报告 + 用药处方 + 高危升级 + 复诊建议
```

**四段式输出**：诊断结论 → 处置处方 → 农事预防 → 复诊与升级

**关键设计**：所有用药名称、剂量、间隔天数**全部来自内置植保知识库**，
大模型只做通俗化改写，不做事实生成——**从架构上杜绝幻觉**。
