> 设计原则：先立主线（决策智能体不是识病工具），再拆四层（识别→决策→守门→进化），
> Demo 放在中段高潮位，创新点收尾呼应评分五维。
> 每页给出“该页必须出现的元素”，直接照此制作。
> **2026-10-16 重写**：主线切换为“可进化的农事决策智能体”；技术栈更正为
> PyTorch+torch_npu（昇腾官方适配层）；数字全部替换为实测口径。

## P1 封面
- 作品名「禾医」+ 副标题“**可进化的农事决策智能体**”
- 一句话定位：**会守门、能溯源、越用越准——识别只是感官，决策才是价值**
- 大赛名称/赛道（第十一届华为ICT大赛创新赛·赛题二 AgentArts）/ 队伍与院校

## P2 真问题（用数字说话）
- 60~70亿亩次/年病虫害发生面积；晚疫病3~7天毁棚；基层植保员缺口
- “通用大模型答农业用药会幻觉”——放一张真实翻车截图对比
- **关键转折页**：PlantVillage 上任何队都能训出 95%+ 的识别模型——**“能认病”本身零信息量**，
  农民真正要回答的是四个问题（此页立主线，后面每层回答一问）：

| 农民的问题 | 禾医的答案 |
|---|---|
| 这是什么病？ | 跨域识别（28.3%→69.82%） |
| 那该怎么办？ | 可溯源处方 + 高危升级卡 |
| 没把握时呢？ | 守门：不猜，转人工 |
| 下次能更准吗？ | 进化：复诊反馈闭环 |

## P3 方案总览（架构图，四层主线）
- 四层：**识别层 / 决策层 / 守门层 / 进化层**（自上而下即用户价值递进）
- 底层：昇腾 910B 训练（PyTorch+torch_npu）→ ATC 转 Ascend310B4 端侧 OM；
  语言层 AMD LLMGateway（DeepSeek 双模型）；平台侧 AgentArts 部署（runtime_app/五Agent编排/MCP SSE）
- 华为云图标标注（昇腾、OBS、AgentArts 等，按实际用了的标）

## P4 数据与模型（识别层）
- PlantVillage 54k 源域 + PlantDoc 田间目标域（原图级划分，MD5 级无泄漏）
- **跨域泛化 28.3%→69.82%**（5 折交叉集成主口径，单折 66.67%±1.05pp）
- 与少样本域适应 54.24%、UDA 28.42% 同基准对比表（文献来源标清楚）
- 口径声明一行字（诚实优先：5 折交叉、444 干净测试样本、TTA）
- 工程诚实：NPU 训练实录日志 + 评测 JSON 可复核

## P5 决策层：防幻觉可溯源（本届重点页）
- 事实-语言分层：51 条×6 字段结构化知识库 = 唯一事实源；LLM 只做语言组织
- 每条处方带**来源标注**（知识库条目 ID）——农药名/剂量可逐条溯源
- 高危病害（晚疫病/黄龙病/病毒类）**强制红色升级卡**：隔离病株 + 联系植保站
- 演示截图：诊断报告页（症状/条件/处置/预防 四段式 + 升级卡特写）

## P6 守门层：承认不确定（差异化核心）
- 置信度守门曲线：τ=0.6 时“病叶判成健康”**10.09%→0.00%**（高危 5 类评测）
- 代价敏感训练**证伪记录**（A/B 实验：-2.0pp）——体现方法严谨性，这是加分项不是黑历史
- 一句话：**对农药决策来说，承认不确定比自信犯错值钱**

## P7~P8 现场Demo（高潮，按新脚本 7 镜头）
- P7：上传晚疫病照片 → 秒级诊断（实测 87.5% 置信，CPU+TTA）→ 可溯源处方 + 升级卡
- P8：健康叶片对照无误报 → 农事问答（RAG 引用）→ **反馈入口**（复诊/误诊回流）
- 备播：预录视频兜底（现场网络风险）；启动前确认 AMD API Key 已配（见 docs/04 清单）

## P9 进化层：越用越准
- 数据闭环：诊断留痕 → 复诊对比 → 误诊反馈回流 → 下一版模型迭代（feedback 数据通道）
- 真实数据计划：自采田间数据入库工具链（registry.json 全溯源）——答辩可讲“我们正在做的事”

## P10 创新点总结（对齐评分五维）
1. **可进化决策闭环**（识别→决策→守门→进化，区别于识病工具）— 创新性
2. 防幻觉可溯源（事实-语言分层）— 技术复合性
3. 跨域泛化 28.3%→69.82%（文献同基准）— 创新性/社会效益
4. 高危守门 10.09%→0（农业安全）— 社会效益
5. 端云边 + AgentArts 平台部署 + MCP 七工具 — 系统复杂性/功能完备性

## P11 华为技术栈运用清单
- 表格逐项：昇腾 910B 训练实录 / ATC→Ascend310B4 OM / AgentArts runtime / MCP SSE /
  语言层（AMD LLMGateway 对照实现）——用了什么/在哪用/证据位置

## P12 社会价值（绿色发展叙事）
- 农户（免费诊断+防误诊）/ 合作社（处方工具）/ 植保部门（测报数据资产）
- **绿色防控**：对症用药减少过量施药 → 农残与面源污染下降（对标往届“绿色发展荣誉”叙事）
- 数字尽量给区间与来源，不编造

## P13 路线图 + 结尾
- 已交付 → 自采数据上线 → 田间物联网相机巡检 → 鸿蒙端侧 App
- 收尾一句话：**“识别准确率只是这个决策系统的一个参数——它不敢瞎猜、每步可溯源、每次使用都在变强。”**
