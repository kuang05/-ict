## P1 封面
- 作品名「禾医」+ 副标题"农作物病虫害智能诊断与防控决策平台"
- 大赛名称/赛道（第十一届华为ICT大赛创新赛·赛题1）/ 队伍与院校

## P2 真实问题（用数字说话）
- 60~70亿亩次/年病虫害发生面积；晚疫病3~7天毁棚；基层植保员缺口
- "通用大模型答农业用药会幻觉"——放一张真实翻车截图对比
- 一句话定位：**拍照→诊断→开方→留痕 的植保闭环**

## P3 方案总览（架构图）
- 四层：用户端 / 应用服务 / 推理引擎 / 智能体+知识库
- 华为云图标标注：ModelArts、MindSpore、昇腾、MaaS、OBS、IoTDA
- 强调"端-云-边"三级推理

## P4 数据与模型
- PlantVillage：54,306张/14作物/26病害/38类
- ResNet迁移学习（MindSpore主栈+PyTorch对照），预期/实测Top-1
- Demo基线模型说明（75%@6类，如实标注）——体现工程诚实

## P5 智能体设计（本届加分点，重点页）
- 工具层四Tool图示：query_kb / kb_search / treatment_plan / escalation_check
- 编排层：诊断解释流 + RAG问答流
- **防幻觉设计**：LLM只做语言组织，事实全部可溯源知识库

## P6~P7 现场Demo（高潮）
- P6：上传晚疫病照片 → 结果页截图（置信度+红色升级卡）
- P7：健康叶片对照 + 农事问答实录 + 诊断留痕列表
- 备播：预录视频兜底（现场网络风险）

## P8 创新点总结（对齐评分）
1. 事实-语言分层智能体（防幻觉/可信AI）
2. 高危病害自动升级（诊断→防控决策）
3. 三级推理引擎+背景掩膜特征（工程降本）
4. 诊断数据资产化（工具→平台外延）
